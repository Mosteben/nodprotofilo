# موقع نادين محمد — الموقع الشخصي

موقع شخصي فاخر لطالبة علوم تربوية وكاتبة، مبني بـ Next.js 15 (App Router) و
TypeScript و Tailwind CSS و Framer Motion.

## التشغيل محليًا

```bash
npm install
npm run dev
```

افتحي http://localhost:3000

## قرارات التصميم

- **الألوان**: الكحلي `#0B1F3A` والذهبي `#D4AF37` والبني `#6F4E37` كما هو مطلوب بالضبط.
- **الخطوط**: `Aref Ruqaa` للعناوين الكبيرة (أقرب خط ديواني متاح مجانًا على
  Google Fonts)، و`Cairo` للنصوص، و`Tajawal` لعناصر الواجهة (الأزرار، التنقل).
  لم يُستخدم الخط الديواني في أي فقرة طويلة، التزامًا بالمواصفات.
- **العنصر المميز (Signature)**: خط حبر ذهبي مرسوم بالحركة (Ink Stroke) يظهر
  أسفل العنوان الرئيسي في البطل، ويتكرر بهدوء كزخرفة أسفل عناوين الأقسام —
  يرمز لهوية الكاتبة دون إفراط في الحركة.
- **البنية**: كل قسم مبني كمكوّن مستقل قابل لإعادة الاستخدام، مقسّم بين
  `components/ui` (عناصر أساسية)، `components/layout`، `components/home`،
  و`components/{articles,lectures,books,gallery,resources,contact}`.

## البنية الكاملة للمجلدات

```
app/                    → المسارات (App Router)
  about/ articles/ lectures/ books/ resources/ gallery/ contact/
  sitemap.ts robots.ts rss.xml/route.ts
components/
  ui/                   → عناصر واجهة قابلة لإعادة الاستخدام
  layout/                → Navbar, Footer
  home/                  → أقسام الصفحة الرئيسية
  shared/                → عناصر مشتركة (PageHeader, Timeline, JSON-LD...)
  articles/ lectures/ books/ gallery/ resources/ contact/
lib/
  constants/             → site.ts (روابط وتنقل) و content.ts (بيانات تجريبية)
  utils.ts
types/                   → أنواع TypeScript المشتركة
```

## ما تم إنجازه بالكامل

جميع الصفحات الثماني المطلوبة (الرئيسية، من أنا، المقالات + صفحة مقالة،
المحاضرات + صفحة محاضرة، الكتب + صفحة كتاب، الموارد، معرض الصور، تواصل معي)
بالإضافة لصفحة 404، مع: بحث وفلترة حية للمقالات والموارد، صفحات ديناميكية
(`generateStaticParams`)، معرض صور Masonry مع Lightbox، مشغّل يوتيوب مضمّن،
شريط تقدّم القراءة، زر العودة لأعلى، زر واتساب عائم، sitemap.xml و robots.txt
وRSS، وبيانات Schema.org لكل مقالة.

## ما يحتاج قرارًا منكِ قبل البناء (لوحة التحكم)

لوحة تحكم حقيقية (مصادقة، صلاحيات، CRUD للمقالات/الفيديوهات/الكتب/الصور/
الموارد، محرر الصفحة الرئيسية، تحليلات) تحتاج قاعدة بيانات فعلية ومزوّد
مصادقة — بناؤها بشكل وهمي (بدون قاعدة بيانات حقيقية) سيكون عديم الفائدة أو
غير آمن لو نُشر مباشرة. الخطوة التالية المقترحة:

1. اختيار قاعدة بيانات (مثل Postgres عبر Supabase أو Neon، أو مباشرة Prisma).
2. اختيار مزوّد مصادقة (NextAuth / Clerk / Supabase Auth).
3. عندها يتم استبدال البيانات التجريبية في `lib/constants/content.ts` باستعلامات
   حقيقية من نفس القاعدة، وبناء `/admin` بصلاحيات محمية.

حتى ذلك الحين، إدارة المحتوى تتم يدويًا عبر تعديل `lib/constants/content.ts`
مباشرة — وهذا ما طلبه البريف تحديدًا ("حتى يتم الإعداد، يُسمح بالإدارة اليدوية").

## استيراد فيسبوك ويوتيوب

لم يتم عمل Scraping لأي منهما (كما طُلب). البنية التجريبية جاهزة للربط
لاحقًا بـ YouTube Data API لسحب الفيديوهات تلقائيًا، وبأي أداة استيراد شرعية
لمنشورات فيسبوك العامة عند توفر مفاتيح API.

## الأداء وإمكانية الوصول

- مكوّنات الخادم (Server Components) هي الافتراضي؛ التفاعلية (`"use client"`)
  مستخدمة فقط حيث يلزم (نماذج، فلاتر، حركات).
- تحسين الصور عبر `next/image`.
- تباين ألوان مطابق لـ WCAG، حالات تركيز (`:focus-visible`) واضحة، واحترام
  `prefers-reduced-motion`.
